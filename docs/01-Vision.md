# Architect's Note

StageArtは、舞台芸術に関わる現場の課題から生まれたプロダクトである。

本Blueprintは単なる仕様書ではない。

StageArtというプロダクトが、どのような思想で設計され、どのような価値を提供することを目的としているのかを定義する設計書である。

今後StageArtに新しい機能を追加する場合も、設計を変更する場合も、すべての判断は本Blueprintに示すVisionおよびDesign Principlesに従う。

StageArtでは実装よりも設計を優先する。

コードはBlueprintを実現するための手段であり、BlueprintこそがStageArtの唯一の設計基準（Single Source of Truth）である。

# Vision

> **StageArtは劇団の運営を管理するためのシステムではない。**
>
> **舞台芸術に関わる人が、運営業務に追われることなく、創作活動に集中できる時間を増やすためのプラットフォームである。**

舞台芸術の現場では、公演を成功させるために多くの事務作業が発生する。

劇団運営、公演制作、予約管理、受付、会計、広報、メンバー管理など、多くの業務は創作活動そのものではない。

しかし、それらは舞台芸術を継続するために欠かすことのできない活動でもある。

StageArtは、それらの運営業務を一つのプラットフォームへ統合することで、舞台芸術に関わるすべての人が、本来最も価値を生み出す「創作」に集中できる環境を提供する。

---

# 1. StageArtとは

StageArtは舞台芸術団体向け統合運営プラットフォームである。

StageArtは単なるチケット予約システムではない。

劇団運営、公演制作、観客とのコミュニケーション、公演終了後の分析まで、一つのプラットフォームとして提供することを目指す。

利用者はシステム内部の構造を意識する必要はない。

StageArtは利用者の「やりたいこと」を起点として動作し、内部ではDomain Modelに基づき必要な情報を自動生成・管理する。

---

# 2. Mission

舞台芸術に関わるすべての人が、本来の創作活動に集中できる環境を提供する。

StageArtは運営業務を効率化することを目的とするのではない。

運営業務を支援することで、創作活動へ使える時間を最大化することを目的とする。

---

# 3. Product Goal

StageArtは劇団運営に必要なすべての情報を一元管理するプラットフォームを目指す。

最終的には以下のドメインを統合する。

・劇団管理
・公演制作
・チケット販売
・受付
・稽古管理
・メンバー管理
・予算管理
・収支管理
・劇団会計
・ファンクラブ
・グッズ販売

---

# 4. MVP

StageArt v1.0では以下のみを提供する。

・劇団登録
・公演登録
・チケット予約
・QRチケット
・当日受付

MVPでは、一つの公演を最初から最後まで運営できる状態を実現する。

---

# 5. Long Term Vision

StageArtは舞台芸術向けERPを目指す。

劇団設立から公演企画、公演制作、チケット販売、公演終了後の収支分析、次回公演の企画まで、一連の活動を一つのプラットフォームで支援する。

---

# Epilogue

> **私たちはソフトウェアを作るのではない。**
>
> **舞台芸術の未来を支える基盤を作る。**

StageArtは、劇団のためだけのシステムではない。

舞台芸術に関わるすべての人が、より良い作品を創り、より多くの人へ届けるための基盤である。

そのため、本Blueprintに記載されるすべての設計判断は、「創作活動に集中できる時間を増やす」というVisionを最優先の判断基準とする。
