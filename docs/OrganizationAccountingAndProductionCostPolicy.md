# 団体会計と公演原価の管理方針

## 1. 目的と役割分担

StageArtでは、団体会計と公演会計の表示目的を分ける。ただし、会計Factの正本はJournal Entryとし、同じ取引を別帳簿として二重登録しない。

- **団体会計**：団体全体の財務状態と、配下の公演ごとの売上・原価・収支を把握する。
- **公演会計**：個々の公演について、費目別原価、売上の内訳、取引明細、決算状態を確認する。
- 団体会計から対象公演の公演会計へ遷移し、詳細を確認できるようにする。

## 2. 団体会計の公演別実績

団体会計では、配下の公演について次の情報を公演単位で表示する。

- 公演名
- 売上
- 原価
- 収支（売上 − 原価）
- 決算状態

複数公演の合計も確認できるようにする。団体会計の公演別実績には費目別の細目や個々の取引を重複表示せず、必要な詳細は公演会計で確認する。

公演別実績はJournal Entryを正本として集計する。同一のJournal Entryを団体会計・公演会計から参照し、決算確定時に売上・原価の集計額を別の仕訳として再転記しない。

Productionが会計期間末時点で決算未確定の場合、当該Productionに係る売上残高を期末に「仮売上」へ振り替える。Check In時点では仮売上への振替を行わない。仮売上は正式な売上・損益に含めず、Production決算確定時に正式な売上へ振り替える。

## 3. 公演会計の費目別原価と取引明細

公演会計では、消耗品費、会場費、広告宣伝費などの費目別原価と、その根拠となる取引明細を保持する。

会計上の振替によって費用勘定の残高が変わっても、元の取引、費目分類、公演との対応関係および原価管理上の履歴を失ってはならない。会計勘定残高と、公演管理上の費目別原価情報は区別する。

費目別原価の表示は、元の取引とその公演への帰属情報に基づいて行う。公演仕掛金への振替や売上原価への振替を、費目別実績として二重に加算しない。

## 4. 会計期間をまたぐ公演と公演仕掛金

会計期間末時点でProduction決算が未確定の場合、そのProductionに帰属する原価は個々のPerformanceの実施済み・未実施に分けず、Production決算確定まで持ち越す。対象となる原価は資産科目「公演仕掛金」として管理する。

基本仕訳は次のとおりとする。

1. 原価取引発生時：借方に該当する費用科目、貸方に現金・預金・未払金等を計上する。
2. Check In時点では、仮売上への振替仕訳を行わない。
3. 対象会計期間の期末：借方「公演仕掛金」、貸方に振替対象の費用科目を計上する。同じ期末処理で、決算未確定Productionの売上残高を仮売上へ振り替える。仮売上の仕訳方向・相手勘定はAccount / Journal Entry仕様と整合させる。
4. Production決算確定時：仮売上を正式な売上へ振り替え、あわせて借方「売上原価」、貸方「公演仕掛金」を計上し、当該公演に対応する仕掛金を振り替える。各振替の貸借・Account Typeの詳細は関連会計仕様と整合させる。

期末仕訳日は対象会計期間の末日とし、公演決算確定時の振替仕訳日は公演決算確定日とする。これらの仕訳は元の取引と公演に関連付け、監査可能な履歴を保持する。

以下を必須とする。

- 仕掛金残高は対象公演と元取引まで追跡できること。
- 期末に仮売上へ振り替えた金額は対象Productionおよび元の売上Journal Entryまで追跡でき、Production決算確定まで正式な売上・損益に含めないこと。
- Check In時点では仮売上への振替を行わないこと。
- Production決算確定時に仮売上を正式な売上へ振り替え、同一売上を二重計上しないこと。
- 仕掛金に計上した金額を、同じ期間の費用・原価として二重に認識しないこと。
- 公演会計では、仕掛金への振替中も元取引に基づく費目別原価と取引明細を確認できること。
- 公演決算確定時の売上原価振替は会計仕訳であり、公演別実績の集計額を別途転記する処理ではないこと。
- 仕掛金への振替と、その後の売上原価への振替を公演別実績に二重加算しないこと。

仕掛計上の対象期間はProduction単位とし、会計期間末までに一部または全部のPerformanceを実施済みであっても、Production決算が未確定であれば、当該Productionに直接帰属する原価を決算確定まで持ち越す。実施済みPerformanceと未実施Performanceの間で原価を配分しない。複数Productionに共通する費用および団体全体の一般管理費は団体会計の費用として処理し、個々のProductionへ按分・配賦しない。これらの共通費を公演仕掛金へ振り替えたり、公演別原価へ含めたりしてはならない。公演仕掛金の対象は、特定のProductionに直接紐づく費用に限る。

## 5. 公演決算の確定と団体会計への反映

公演決算確定は、個別公演の未収金・未払金等の精算と必要な会計処理が完了したことを示す。これは団体全体の会計期間締めとは別の操作である。

会計期間末には、決算未確定Productionの売上残高を仮売上へ振り替え、公演原価を公演仕掛金へ振り替える。公演決算確定時には、対象公演の仮売上を正式な売上へ振り替え、公演仕掛金を売上原価へ振り替える。これにより当該Productionの売上・原価・収支が正式に確定する。団体会計の公演別売上・原価・収支は、同じ会計Factを正本として集計し、集計結果だけを新しいJournal Entryとして転記しない。

決算確定後に会計上の誤りが判明した場合は、確定済みのJournal Entryを直接変更・削除せず、既存の訂正・Adjustment方針に従う。

## 6. 会計期間の管理

会計期間はOrganization単位で管理する。会計期間の開始日・終了日を明確にし、各Journal EntryのJournal Dateに基づいて対象期間へ集計する。

会計期間の開始月の設定方法、初期値、期間の締め処理、締め済み期間への訂正手順は、既存の会計期間・Journal Entry仕様と照合して確定する。これらが未定義の場合、実装で独自の既定値や締め処理を導入しない。

## 7. 表示上の原則

- 団体会計は、公演ごとの売上・原価・収支と団体全体の状況を簡潔に表示する。
- 公演会計は、費目別原価、売上内訳、取引明細を表示する。
- 公演仕掛金は団体会計上の資産として扱い、当期費用と重複計上しない。
- 期末に仮売上へ振り替えた決算未確定Productionの売上は正式な売上・損益に含めず、Production決算確定時に正式な売上へ振り替える。
- 元取引の費目分類・公演との関連は、会計振替後も保持する。
- 同じ売上・原価・Journal Entryを複数の集計経路で二重計上しない。

## 8. 会計処理上の留意点

本方針はStageArt内の会計Factの管理、集計および表示責務を定める。収益認識時点、仕掛計上対象の具体的な原価範囲、複数公演日がある場合の配分、税務上の処理は、団体の会計方針および適用される会計基準に従って確定する。仕様に未確定事項がある場合は、実装前に確認する。
