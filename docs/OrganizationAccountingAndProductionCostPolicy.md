# 団体会計と公演原価の管理方針

## 1. 目的と役割分担

StageArtでは、団体会計と公演会計の役割を分ける。

- **団体会計**：団体全体の会計状況を把握する。公演に関する実績表示は、公演ごとの売上・原価・収支を中心とする。
- **公演会計**：個々の公演の採算を管理する。費目別の原価、売上の内訳、個々の取引などの詳細を保持・表示する。
- 団体会計で詳細な費目・取引明細を重複して管理するのではなく、詳細確認が必要な場合は対象公演の会計明細へ遷移できる構成とする。

## 2. 団体会計の公演別実績

団体会計では、配下の公演について次の情報を公演単位で確認できるようにする。

- 公演名
- 売上
- 原価
- 収支（売上 − 原価）
- 決算状態（確定前／確定済み等、必要な状態）

複数公演の合計も確認できるようにする。公演の詳細な費目別内訳や取引明細は、公演会計側で確認する。

ここでいう公演別実績は、公演会計の原価・売上データを基礎とする。団体会計と公演会計で同じ取引を独立して二重管理しない。

## 3. 公演の費目別原価

公演会計では、消耗品費、会場費、広告宣伝費などの費目別原価と、その根拠となる取引明細を保持する。

会計上の振替によって費用勘定の残高が変わっても、公演管理上の費目別原価情報や元取引の履歴を失ってはならない。会計勘定残高と、公演の原価管理情報は区別して扱う。

## 4. 期をまたぐ公演と仕掛品

公演が会計期間をまたぎ、期末時点で未完成である場合、未完成の公演に直接対応する原価のうち仕掛品として繰り延べるべきものを、団体会計では仕掛品として計上する。

- 期末の団体会計では、対象となる未完成公演の原価は仕掛品残高として把握する。
- 仕掛品として計上されている金額を、当期に確定した公演原価・費用として重複計上しない。
- 仕掛品の残高は、公演との対応関係を追跡できるようにする。
- すべての支出を一律に仕掛品とするのではなく、会計上の基準に従い、未完成公演に対応する原価を対象とする。
- 公演会計側では、仕掛品への振替中も費目別原価と取引明細を参照できる状態を維持する。

## 5. 公演決算の確定と団体会計への反映

公演決算を確定したときは、当該公演に対応する仕掛品を適切に振り替え、公演の売上と原価を確定する。その確定結果を団体会計の公演別実績へ反映する。

団体会計では、確定した公演ごとの売上・原価・収支を把握できればよく、詳細な費目別内訳は公演会計で確認する設計とする。

公演決算の確定に伴う団体会計への反映は、同じ売上・原価が二重に計上されないよう、元の取引、期末の仕掛品計上、仕掛品の振替、および公演別実績の集計を関連付けて管理する。

## 6. 表示上の原則

- 団体会計は全体把握と公演間の比較を優先し、公演ごとの売上・原価・収支を簡潔に表示する。
- 公演会計は詳細把握を優先し、費目別原価・売上内訳・取引明細を表示する。
- 仕掛品は団体会計上の資産として扱い、未確定の公演原価と確定済みの公演原価を混同しない。
- 仕掛品への会計振替後も、公演会計における原価の費目分類と履歴は保持する。

## 7. 会計処理上の留意点

本方針はStageArt内の表示・データ管理の役割分担を定めるものであり、個別の仕訳科目、収益認識時点、仕掛品に含める原価の範囲、税務上の処理は、団体の会計方針および適用される会計基準に従って確定する。
