# Purpose

本書は、一般Member向けの小口立替経費申請における入力項目、証跡の扱い、経費分類、および仕訳生成タイミングを定義する。

本書は `ExpenseApprovalWorkflow.md` を補完する。承認権限、通知、会計Actual、Journal Entryの訂正など、同文書で定義済みのルールは引き続き同文書に従う。

---

# Member Submission UI

一般Memberが経費申請時に入力する必須項目は次の2つとする。

1. 経費種類
2. 立替金額

申請者はレシート・領収書等の証跡を添付できるが、添付は必須としない。

申請者や申請日時など、システムが特定できる情報は自動記録し、申請者に手入力させない。

申請画面では、仕訳、借方・貸方、勘定科目、会計コード等の会計入力を要求しない。一般Memberだけでなく、承認者を含む利用者に手作業での仕訳入力を要求しないことを基本方針とする。会計上の仕訳はシステムが生成する。

備考・説明欄は、必要に応じて追加できる任意項目とする。証跡がないことだけを理由に申請を拒否する入力制御は設けない。

# Expense Categories and Account Mapping

申請時に選択できる経費種類は、当面、次の2種類とする。

| 申請時の経費種類 | 対象例 | 承認時に使用する借方勘定科目 |
|---|---|---|
| 物品購入 | 消耗品などの小口物品購入 | 消耗品費 |
| 交通費 | 電車・バス等の交通費、駐車場代を含む | 旅費交通費 |

申請者に勘定科目を選択させない。経費種類からシステムが勘定科目を決定する。

この分類は小口立替Expenseを対象とした最小構成とする。新しい分類や科目を追加する場合は、既存の会計仕様と整合する形で別途定義する。

# Evidence and Return for Correction

レシート・領収書等の証跡は任意とする。証跡が添付されていない申請も提出できる。

承認者は申請内容を確認し、証跡や説明が必要と判断した場合は、理由を明示して申請者に差し戻し、必要な情報の追加を求めることができる。

差し戻し理由は必須とする。申請者は差し戻し理由に従い、証跡の追加、説明の追記、申請情報の修正を行い、再申請できる。

差し戻し中は会計仕訳を生成せず、Actualにも反映しない。差し戻し・再申請の履歴は追跡可能とする。

差し戻しは、申請者が修正して再申請できる業務上の処理とする。実装時には既存のExpense状態モデルを確認し、再申請を妨げる終端的な却下状態と混同しないこと。既存状態を変更または追加する必要がある場合は、実装前に影響範囲を確認する。

# Journal Generation Timing

申請時点ではJournal Entryを生成しない。

SUBMITTED中のExpenseは申請データとして保持し、正式なAccounting Actualに含めない。証跡が添付されていない場合も、この原則は変わらない。

承認時に、システムが承認対象の経費種類と承認金額に基づいてJournal Entryを自動生成し、承認と会計転記を同一の業務処理として完了させる。利用者に別途仕訳入力やPosting操作を要求しない。

承認時の基本仕訳は次のとおり。

| 経費種類 | 借方 | 貸方 |
|---|---|---|
| 物品購入 | 消耗品費（承認金額） | 未払金（承認金額） |
| 交通費（駐車場代を含む） | 旅費交通費（承認金額） | 未払金（承認金額） |

支払・精算時には、実際の支払方法に応じて未払金を消し込む。

| 支払方法 | 借方 | 貸方 |
|---|---|---|
| 現金で精算 | 未払金 | 現金 |
| 銀行振込で精算 | 未払金 | 普通預金 |

実際の勘定科目コードや既存会計モデルへの登録方法は、リポジトリ内の既存勘定科目・Journal Entry設計を利用し、同じ科目を重複作成しない。

# Approval Amount and Existing Workflow Compatibility

申請金額と承認金額の扱い、承認者の権限、承認後の訂正は `ExpenseApprovalWorkflow.md` の定義に従う。

承認金額を申請金額と異なる額に変更する既存仕様がある場合、その差額の履歴を保持し、ActualとJournal Entryには承認金額のみを反映する。

ただし、現在の実装に明細配分等の未定義ルールを理由として金額変更を拒否する制約がある場合は、その制約と本書・既存仕様の差を実装前に報告すること。仕様間の不一致を推測で解消したり、会計上の配分ルールを独自に作ったりしない。

# Business Rules

- 一般Member向けの経費申請で必須なのは経費種類と立替金額である。
- レシート・領収書等の証跡は任意であり、未添付でも申請できる。
- 経費種類は当面「物品購入」「交通費」の2種類とする。
- 「交通費」には駐車場代を含める。
- 物品購入の借方科目は「消耗品費」とする。
- 交通費の借方科目は「旅費交通費」とする。
- 承認時の貸方科目は「未払金」とする。
- 申請者に仕訳や勘定科目を入力させない。仕訳はシステムが自動生成する。
- 申請時点では仕訳を生成せず、正式なActualにも反映しない。
- 承認時に承認金額に基づく仕訳を自動生成し、Actualへ反映する。
- 証跡や説明が必要な場合、承認者は理由を明示して差し戻せる。
- 申請者は差し戻し理由に従って情報を追加・修正し、再申請できる。
- 差し戻し中は仕訳を生成しない。
- 精算時には「未払金／現金」または「未払金／普通預金」で消し込む。
- POSTED済みJournal Entryの直接変更・削除を禁止し、訂正は既存のReversal / Adjustment原則に従う。
